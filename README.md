- бьёт в главную боль рынка — систему внедрили, но ей не пользуются;

- отстраивает от фрилансеров и «настроил и исчез»;

## Как открыть

```bash
cd /home/paladin/site
python3 -m http.server 8080
# http://localhost:8080
```

Или просто открыть `index.html` в браузере.

## Что заменить перед публикацией

1. **Бренд и контакты** — «София», телефон, e-mail, мессенджеры, юридические ссылки.
2. **Цифры** — 120+ проектов, 94%, кейсы и цены. Оставляйте только реальные данные.
3. **Форма** — в `index.html` найдите комментарий `// Пример отправки` и подключите endpoint:
   ```js
   fetch('/api/lead', { method: 'POST', body: new FormData(form) });
   ```
   либо отправку в CRM/Telegram/почту. Сейчас форма показывает экран «Заявка отправлена» без отправки.
4. **Политика конфиденциальности** — замените `href="#"` на реальный документ (требование 152-ФЗ).
5. **Tailwind для продакшена** — CDN не предназначен для боевого сайта. Соберите CSS:
   ```bash
   npm install -D tailwindcss
   npx tailwindcss -i ./src/input.css -o ./dist/output.css --minify
   ```
   и замените `<script src="https://cdn.tailwindcss.com">` на `<link rel="stylesheet" href="./dist/output.css">`.

## Технические детали

- Адаптив: mobile-first, контрольные точки `sm / lg`.
- Мобильное меню, аккордеон FAQ (`<details>`), scroll-reveal на `IntersectionObserver`, липкий CTA на мобильных.
- Доступность: `aria-expanded` у меню, `label` у полей, `prefers-reduced-motion`, `noscript`-фолбэк для анимаций.
- Цвета и шрифт заданы в `tailwind.config` внутри `index.html`.
